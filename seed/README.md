# Sprite seed

`workspace.tar.gz` is unpacked into `/workspace` on every new sprite (`lib/sprites.ts`). It is Bottle at `BOTTLE_COMMIT` (`lib/seed.ts`) with each patch in `bugs/` applied, committed as a fresh one-commit repo. Upstream history is left out because it contains the fixes. Rebuild with `npm run seed`; it needs network access and `python3`, and it refuses to build if the clean suite fails or any bug's test passes.

Each patch reverses only the `bottle.py` half of a real upstream fix. The fix's regression test stays, so it fails until the bug is fixed. Player-facing text lives in `SEED_BUGS`; these notes are for maintainers only.

The test also requires an unquoted value not to match.                                         |
